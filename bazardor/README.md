# BazarDor — বাজার দর

BazarDor is a responsive web application that helps users explore daily market prices of essential products in Bangladesh.

## Features

- View daily prices of essential market products.
- Browse products by category.
- Sort products by price.
- Compare today's prices with previous prices.
- View product details and market price information.
- User registration and login.
- Responsive design for mobile, tablet, and desktop.
- Loading and error states for a better user experience.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- REST API

## Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure the required environment variables in `.env.local`.
4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.
